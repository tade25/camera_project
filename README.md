# camera project

## v0.1.0(2026-04-21)
- 基础工程

## v0.2.0(2026-05-07)
- 新增实时fps统计与打印
- 集成PXP硬件转码, 替代原CPU软件实现的YUYV转RGB565, 解决帧率过低问题
- 改造驱动及应用层代码，通过物理地址直传实现零拷贝，进一步提升帧率
- 修复系统运行一段时间后画面出现垂直分割的问题, 640x480分辨率全流程30fps稳定运行

## v0.3.0(2026-05-16)
- dts新增csi与ov5640的v4l2子设备port/endpoint绑定
- 驱动重构为标准V4L2子设备架构, 实现异步子设备自动探测绑定
- 驱动支持640x480、1280x720两种主流分辨率动态适配切换
- 驱动完善资源管理与全流程异常错误处理
- 驱动补齐全套V4L2标准接口，支持帧格式、分辨率、帧率信息枚举与流参数配置，修复子设备接口调用及结构体访问异常
- 应用层深度适配底层新特性，新增设备参数枚举、自定义帧率配置，适配多分辨率动态切换能力
- 应用层优化采集架构，采用poll非阻塞采集模式，增加超时重试容错逻辑，剥离软件图像转换代码并精简冗余逻辑，有效提升采集稳定性与兼容性
